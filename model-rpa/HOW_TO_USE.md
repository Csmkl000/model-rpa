# Model-RPA 使用说明

## 快速开始

### 1. 启动应用

```powershell
cd model-rpa
bun run tauri dev
```

等待应用窗口打开。

---

### 2. 首页

你会看到：
- **Model-RPA** 标题
- **"打开编辑器"** 按钮 - 点击进入工作流编辑
- **"导入工作流"** 按钮 - 导入已有工作流

---

### 3. 工作流编辑器

点击 **"打开编辑器"** 后，进入工作流编辑界面：

#### 左侧 - 节点面板
- 点击节点按钮，会添加到中间画布
- 节点类型：
  - 🖱️ **动作** - 点击、输入、选择
  - 📊 **数据提取** - 抓取网页数据
  - 🔄 **循环** - 重复执行、翻页
  - 🔀 **条件判断** - 根据条件分支
  - ⏱️ **等待** - 等待时间或条件
  - 🔔 **通知** - 发送通知
  - 📝 **变量** - 变量操作
  - 📜 **脚本** - 执行代码
  - 🛡️ **错误处理** - 处理错误
  - 🤖 **Agent** - AI 自主执行

#### 中间 - 画布
- 显示已添加的节点
- 点击节点选中（高亮显示）
- 选中后可以删除

#### 右侧 - 浏览器视图
- 输入网址，点击"前往"打开网页
- 用于录制操作或实时监控

#### 顶部工具栏
- **← 返回** - 回到首页
- **📊 显示日志** - 显示/隐藏执行日志
- **▶️ 执行** - 执行工作流

---

### 4. 创建一个简单工作流

**示例：自动打开百度搜索**

1. 点击 **"打开编辑器"**
2. 点击左侧 **"🖱️ 动作"** 添加动作节点
3. 点击画布上的节点，输入指令："打开百度"
4. 再添加一个动作节点，输入："输入搜索词"
5. 再添加一个动作节点，输入："点击搜索"
6. 点击 **"▶️ 执行"** 运行工作流

---

### 5. 常见操作

| 操作 | 方法 |
|------|------|
| 添加节点 | 点击左侧节点按钮 |
| 选中节点 | 点击画布上的节点 |
| 删除节点 | 选中节点后点击"删除" |
| 执行工作流 | 点击顶部"执行"按钮 |
| 查看日志 | 点击"显示日志"按钮 |
| 返回首页 | 点击"← 返回"按钮 |

---

### 6. 功能说明

#### 动作节点
- 用于执行点击、输入、选择等操作
- 在右侧配置面板输入指令（大白话描述）

#### 数据提取节点
- 用于从网页抓取数据
- 可以提取列表、文章、商品信息等

#### 循环节点
- 用于重复执行操作
- 常用于翻页、批量处理

#### 条件判断节点
- 用于根据条件分支
- 例如：如果页面包含"已售罄"，执行不同操作

#### Agent 节点
- AI 自主执行复杂任务
- 需要人工确认高危操作

### 8. 常见问题

**Q: 为什么节点没有反应？**
A: 确保已选中节点（高亮显示），然后在右侧配置面板输入指令。

**Q: 如何执行工作流？**
A: 点击顶部工具栏的"▶️ 执行"按钮。

**Q: 如何查看执行日志？**
A: 点击顶部工具栏的"📊 显示日志"按钮。

**Q: 如何返回首页？**
A: 点击顶部工具栏的"← 返回"按钮。

```

```
