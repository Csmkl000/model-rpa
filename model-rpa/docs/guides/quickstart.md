# 快速上手指南

本指南将帮助您在 5 分钟内创建第一个自动化工作流。

## 启动应用

```bash
cd model-rpa
bun run tauri dev
```

应用启动后，您将看到主界面：

- **左侧**：节点面板 - 可拖拽的节点列表
- **中间**：画布区域 - 工作流编辑器
- **右侧**：实时视图 - 内嵌浏览器

## 创建第一个工作流

### 步骤 1：拖拽节点

1. 从左侧面板拖拽 **动作节点** 到画布
2. 连接 **开始** 节点到 **动作节点**

### 步骤 2：配置节点

1. 点击 **动作节点** 打开配置面板
2. 输入指令描述，例如："点击搜索按钮"
3. 选择动作类型：点击、输入、选择等

### 步骤 3：添加数据提取

1. 拖拽 **数据提取** 节点到画布
2. 连接到上一个节点
3. 配置要提取的字段，例如：商品名称、价格

### 步骤 4：执行工作流

点击工具栏的 **▶️ 执行工作流** 按钮。

## 使用录制功能

### 步骤 1：打开录制模式

1. 在右侧实时视图中输入网址
2. 点击 **🔴 开始录制** 按钮

### 步骤 2：录制操作

1. 在浏览器中进行操作（点击、输入等）
2. 左侧画布会自动生成对应节点

### 步骤 3：停止录制

点击 **⏹️ 停止录制** 按钮完成录制。

## 使用安全变量

### 添加凭证

1. 打开设置（系统托盘 → 设置）
2. 切换到 **凭证管理** 标签
3. 点击 **+ 添加凭证**
4. 输入变量名和值，例如：
   - 变量名：`Taobao_Pwd`
   - 值：`your-password`

### 使用变量

在节点配置中使用 `{{变量名}}` 格式引用：

```
在密码框中输入 {{Taobao_Pwd}}
```

## 使用浏览器身份

### 创建身份

1. 打开设置
2. 切换到 **浏览器身份** 标签
3. 点击 **+ 新建身份**
4. 输入身份名称，例如："工作账号"

### 使用身份

1. 在执行工作流前，选择要使用的身份
2. 每个身份拥有独立的 Cookie 和登录状态
3. 扫码登录一次，永久免登录

## 使用定时任务

### 创建定时任务

1. 保存工作流
2. 打开设置 → 定时任务
3. 点击 **+ 新建任务**
4. 配置 Cron 表达式，例如：
   - `0 3 * * *` - 每天凌晨 3 点
   - `*/30 * * * *` - 每 30 分钟

### 查看执行结果

在时间轴面板中查看执行日志。

## 常用操作

### 缓存机制

- 首次执行：调用 AI 分析页面
- 后次执行：使用缓存结果（⚡️ 极速免流）
- 缓存失效：网页改版时自动重新分析

### 错误处理

- **橙色闪烁**：正在自动适应新版网页
- **红色暂停**：需要人工介入（如验证码）
- **绿色完成**：执行成功

### 导出工作流

1. 点击工具栏的 **💾 保存** 按钮
2. 工作流保存为 `.mrpa` 文件
3. 可分享给其他用户
